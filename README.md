# itsbenduncan.com

The premiere issue. A one-page magazine cover in the Side B "Centerfold" style.

- `index.html` is the whole site: styles and the small script are inline.
- `fonts/` holds the self-hosted Latin subsets: Ultra, Yellowtail, Bodoni Moda, Archivo, all under the SIL Open Font License.
- Each day is a new issue. The masthead colour rotates through four colourways and the issue number counts up from launch (2026-10-12). Add `?issue=0` to `?issue=3` to preview a colourway.
- `og.jpg` is the link-preview image and `favicon.png` / `apple-touch-icon.png` are the Side B "B".
- `CNAME` tells GitHub Pages which domain to serve.

Edit the cover lines in `index.html`, then commit and push. GitHub Pages redeploys in about a minute.
